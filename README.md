# The Threshold Collection — built with Wax

Academic digital library for DUT students and early-career researchers (ICTB301, Department of Information Systems, Durban University of Technology).

**Software:** [Wax](https://minicomp.github.io/wiki/wax/) (open-source, minicomp) on the Jekyll static-site generator. Hosted from GitHub on Netlify.

## How the Wax site is organised
| Path | What it is |
|---|---|
| `_data/catalogue.csv` | Dublin Core metadata, one row per item (31 items) |
| `_catalogue/` | Item pages generated by Wax from the CSV (`rake wax:pages catalogue`) |
| `search/index.json` | Search index generated by Wax (`rake wax:search main`) |
| `_config.yml` | Wax settings: collection, search fields, the four shelves, menu |
| `_layouts/`, `_includes/`, `assets/` | Our theme: colours, layout, search and browse |
| `pages/` | Browse, Search, About Us |
| `downloads/` | 12 openly licensed files stored with the site |
| `netlify.toml` | Tells Netlify to run `bundle exec jekyll build` and publish `_site` |

## Add or change an item
1. Edit `_data/catalogue.csv` (Excel is fine; save as CSV UTF-8).
2. On a computer with Ruby: `bundle install`, then
   `bundle exec rake wax:pages catalogue` and `bundle exec rake wax:search main`.
3. Commit the changed files to GitHub. Netlify rebuilds automatically.

## Preview locally
`bundle exec jekyll serve` then open http://localhost:4000
