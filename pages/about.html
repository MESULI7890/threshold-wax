Built for research and discovery

Every item is described with Dublin Core metadata, making it easy to search, cite and share your work. Whether you're writing your first assignment or publishing your first paper, start here with us!

How we built it: Wax

The library is built with Wax, free and open-source digital library software from the Minicomp project, which runs on the Jekyll static-site generator.

  • Metadata spreadsheet: every item is one row in _data/catalogue.csv, using Dublin Core fields.
  • Item pages: rake wax:pages catalogue turns each row into its own record page.
  • Search index: rake wax:search main builds the index that powers the search box, using elasticlunr, the search library included with Wax.
  • Hosting: the source is stored on GitHub, and Netlify rebuilds the site every time we update it.

Dublin Core metadata

Open any item to see its full record. We use 14 of the 15 Dublin Core elements.

ElementWhat we record
TitleFull title as published
CreatorAuthors, or the organisation for reports
ContributorSupervisors (theses) or editors (books)
SubjectKeywords used by search
DescriptionShort plain-language summary
PublisherJournal, university or organisation
DateYear of publication
TypeReport, book, open textbook, journal article, master's or doctoral thesis
FormatPDF, EPUB or HTML, with file size
IdentifierDOI or Handle, the permanent link
SourceWhere the original is published
LanguageISO 639 code (en)
CoverageSouth Africa or International
RightsLicence, for example CC BY 4.0

User interface principles

Simplicity

One search box on the home page, four collections, four menu items. White background and one highly legible typeface (Atkinson Hyperlegible, designed for low-vision readers).

Consistency

Blue always means Research, green Journal articles, purple Theses and dissertations and teal Open textbooks. Every item has the same three buttons in the same order: Read online, Download, View metadata.

Feedback

Live result counts as you type, matching words highlighted in yellow, the selected filter shown in dark, and a message when a citation is copied.

Visibility

The search box is the first thing on the home page, South African work has its own badge, and every download button shows the file type and size before you tap it.

Phones and accessibility

The layout is built for phones first and tested on Android and iPhone screen sizes: buttons are at least 44 pixels tall for thumbs, text never needs zooming, and nothing scrolls sideways. All text meets WCAG AA contrast, and every control works with a keyboard.
